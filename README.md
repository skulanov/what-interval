# Интервальный тренажер

Интерактивное веб-приложение для развития слухового восприятия музыкальных интервалов на основе визуального представления нот на нотном стане.

![Интервальный тренажер](https://img.shields.io/badge/version-1.0.0-blue.svg)
![Status](https://img.shields.io/badge/status-completed-success.svg)

## 📋 Описание проекта

**Интервальный тренажер** — это приложение для тренировки распознавания музыкальных интервалов. Приложение случайным образом генерирует пары нот, визуализирует их на нотном стане и воспроизводит звуки. Пользователь должен угадать интервал между нотами из 13 возможных вариантов.

### Основные возможности

- ✅ **Визуализация нот на нотном стане** — отображение нот на пятилинейном стане со скрипичным ключом
- ✅ **Воспроизведение звуков** — прослушивание первой ноты, второй ноты или обеих вместе (гармонический интервал)
- ✅ **13 музыкальных интервалов** — от унисона до октавы
- ✅ **Отслеживание статистики** — подсчёт правильных ответов и процент успешности
- ✅ **Адаптивный дизайн** — работает на всех устройствах (от 320px до 1920px)
- ✅ **Современный интерфейс** — красивый градиентный дизайн с плавными анимациями

## 🎵 Диапазон и интервалы

### Диапазон нот
От **Bb3** (си-бемоль малой октавы) до **Db5** (ре-бемоль второй октавы) — 16 нот

### Музыкальные интервалы (13 шт.)

| Интервал | Полутонов | Пример |
|----------|-----------|--------|
| Унисон (прима) | 0 | C4 - C4 |
| Малая секунда | 1 | C4 - Db4 |
| Большая секунда | 2 | C4 - D4 |
| Малая терция | 3 | C4 - Eb4 |
| Большая терция | 4 | C4 - E4 |
| Кварта (чистая) | 5 | C4 - F4 |
| Тритон | 6 | C4 - Gb4 |
| Квинта (чистая) | 7 | C4 - G4 |
| Малая секста | 8 | C4 - Ab4 |
| Большая секста | 9 | C4 - A4 |
| Малая септима | 10 | C4 - Bb4 |
| Большая септима | 11 | C4 - B4 |
| Октава | 12 | C4 - C5 |

## 🚀 Функциональные особенности

### Реализованные функции

1. **Генерация упражнений**
   - Случайный выбор двух нот из диапазона Bb3 - Db5
   - Вторая нота всегда выше или равна первой (восходящие интервалы)
   - Проверка интервала (не более 12 полутонов - октавы)
   - Автоматическое воспроизведение при генерации нового упражнения

2. **Визуализация**
   - Отображение нот на пятилинейном нотном стане (без скрипичного ключа)
   - Добавочные линии для нот вне стана
   - Подписи названий нот под каждой нотой
   - Отображение названий текущих нот

3. **Управление аудио**
   - **▶ Первая нота** — воспроизведение первой ноты
   - **▶ Вторая нота** — воспроизведение второй ноты
   - **▶ Вместе** — воспроизведение обеих нот одновременно (гармонический интервал)

4. **Проверка ответов**
   - Выбор интервала из 13 кнопок
   - Визуальная подсветка правильного/неправильного ответа
   - Сообщение о результате (✓ Правильно / ✗ Неправильно)
   - Отображение правильного ответа при ошибке

5. **Статистика**
   - Подсчёт правильных ответов
   - Общее количество попыток
   - Процент успешности
   - Кнопка сброса статистики

## 🎯 Как использовать

### Онлайн (после публикации)

1. Откройте приложение в браузере
2. При загрузке автоматически генерируется первое упражнение
3. Прослушайте интервал (кнопки "▶ Первая нота", "▶ Вторая нота", "▶ Вместе")
4. Выберите интервал из 13 кнопок
5. Получите результат (правильно/неправильно)
6. Нажмите "Новый интервал" для следующей пары нот

### Локально

1. Скачайте все файлы проекта
2. Убедитесь, что структура папок сохранена
3. Откройте файл `index.html` в современном браузере
4. Начните тренировку!

## 📊 Алгоритм генерации упражнений

```javascript
1. Выбрать первую ноту случайно из 16 нот (Bb3 - Db5)
2. Выбрать вторую ноту случайно из 16 нот
3. Вычислить количество полутонов между нотами: midiNote2 - midiNote1
4. Если вторая нота ниже первой (< 0) ИЛИ расстояние > 12 полутонов, 
   вернуться к шагу 2
5. Если вторая нота ≥ первой И расстояние ≤ 12 полутонов, пара валидна
6. Отобразить ноты на стане
7. Автоматически воспроизвести обе ноты вместе
```

**Важно:** Все интервалы генерируются как восходящие (вторая нота всегда выше или равна первой).
